# Contributing to ancalagon-parquet-analyzer

Thank you for contributing to **ancalagon-parquet-analyzer**.

## Guidelines

1. Fork the repository and create a feature branch (`git checkout -b feature/my-feature`).
2. Run TypeScript build and unit tests (`npm test`).
3. Keep all code comments, docstrings, documentation, and commit messages strictly in English.
4. Do not use emojis or decorative icons.
5. Submit a pull request with a clear description.
